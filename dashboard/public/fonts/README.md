# Fonts

Atkinson Hyperlegible Next (v7) and Atkinson Hyperlegible Mono (v8), as
served by Google Fonts: the variable-weight files, Latin and Latin Extended
subsets. Copyright 2020-2024 The Atkinson Hyperlegible Next Project Authors
and The Atkinson Hyperlegible Mono Project Authors. Both are licensed under
the SIL Open Font License 1.1; the licence texts are in this folder.

`app.css` declares them with `@font-face`, so the dashboard serves its own
fonts rather than loading them from a font service.
